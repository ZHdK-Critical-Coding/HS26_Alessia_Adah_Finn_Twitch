Schrift für den Druck-Overlay

Aktiv:
  assets/PRINT_FONT.ttf          → Akkurat Std Mono (vom User)
  assets/AkkuratStd-Mono.ttf     → gleiche Datei unter Originalnamen

Fallback (nur wenn keine eigene .ttf/.otf vorhanden):
  assets/PRINT_FONT.ttf.fallback → Arimo
  danach System-Arial / DejaVu

Der Server wählt automatisch die erste vorhandene Schrift in assets/.
